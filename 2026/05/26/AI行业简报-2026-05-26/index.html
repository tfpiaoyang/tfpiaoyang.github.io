xAI 发布首款 Coding Agent，马斯克身在北京

xAI 发布了其首款 Coding Agent 产品，这是马斯克旗下人工智能公司的重要产品化突破。与此同时，马斯克本人正在北京访问，业界猜测此行与 xAI 在华业务拓展及 Grok 模型后续规划有关。Grok 新模型正在 Colossus 2 集群上训练中，Cursor 团队也已加入 xAI，外界对其后续动作保持高度关注。

三天三家公司超百亿美元：中国 AI 大模型融资决战周

5月7日至8日，中国 AI 大模型赛道迎来融资密集爆发期：月之暗面完成约20亿美元新融资，投后估值突破200亿美元；阶跃星辰即将完成近25亿美元融资，红筹架构已拆除，港股 IPO 路基清障完毕；DeepSeek 融资估值持续刷新，传言已超500亿美元，The Information 报道其计划融资500亿元人民币。业界将这一周称为中国 AI 融资决战周。

Google 搜索框 25 年来首次改变，全面集成 Gemini AI

Google 宣布对其搜索框进行25年来首次重大改造，全面集成 Gemini AI 能力。用户可以直接在搜索框中生成10秒好莱坞级别视频，或通过自然语言提示词完成复杂任务。Google 表示，该功能基于全新的视频生成技术，能够根据”解释教科书片段”或”根据草图渲染虚构角色”等提示词生成视频内容。这标志着 Google 正式将 AI 生成能力深度嵌入其核心搜索产品。

[来源：New York Times] 查看详情 | 2026-05-26

DeepSeek V4-Pro 降价 75%，AI 定价战持续升级

DeepSeek 在发布 V4 系列仅一个月后，宣布将 V4-Pro 价格下调75%。此前 V4-Pro 的使用成本为每百万 tokens（缓存命中）0.0145 美元至每百万输出 tokens 3.48 美元不等。此次大幅降价标志着 DeepSeek 正式加入 AI 模型定价战，与 OpenAI、Anthropic、Google 等头部厂商的价格竞争愈发激烈。

[来源：InfoWorld] 查看详情 | 2026-05-26

SpaceX 与 Anthropic 签署超级算力协议：每月 12.5 亿美元

Anthropic 与 SpaceX 签署协议，获得 SpaceX Colossus 超算集群的访问权，合同金额为每月12.5亿美元，至2029年5月到期。这一数据点让业界对前沿模型算力成本有了更清晰的认识。同时，有消息称某 AI 公司正寻求以1万亿美元估值公开上市，若成功将成为史上最大科技公司 IPO，远超 Facebook（160亿美元）、阿里巴巴（250亿美元）和沙特阿美（294亿美元）之和。

字节跳动按下 AI Agent 加速键，豆包 3.0 同步亮相

字节跳动在 AI Agent 领域动作频频，同步更新了豆包文生图模型至3.0版本。新版本在文字排版、实拍级图像生成效果等方面有显著提升。字节的 AI Agent 产品正在快速迭代，涵盖智能助手、代码生成、多模态理解等多个方向，成为中国 AI Agent 市场的重要玩家。

百度千帆企业级 Agent Infra：累计支持超 130 万 Agents

百度千帆平台已从大模型开发平台扩展为企业级 Agent Infra。公开数据显示，平台累计支持企业构建超130万个 Agents，工具日均调用次数达数千万级，覆盖智能硬件、制造、交通、能源等主流行业，沉淀出获客营销、错题批改等100多个高频场景。百度目标是将 Agent 真正”长”在企业生产线里，提供从模型服务到运行环境的全链路支持。

[来源：36氪] 查看详情 | 2026-05-26

Warp 终端开源：Altman 投资，15 小时 3.5 万 Star

Sam Altman 投资的 AI 终端工具 Warp 宣布开源，该项目在15小时内获得3.5万 GitHub Star。Warp 于2023年4月率先将 OpenAI 大模型直接集成到终端中，实现自然语言生成命令和输出解释，成为 AI 辅助终端领域的开拓者。团队已放弃将 Warp 定义为”终端工具”，而是将其定位为更广泛的 AI 协作平台。

[来源：36氪] 查看详情 | 2026-05-26

Model Context Protocol（MCP）成为 AI 系统互联互通开放标准

Anthropic 于2024年11月推出的 Model Context Protocol（MCP）已逐步成为 AI 系统与外部工具、数据源集成的开放标准。MCP 提供了标准化接口，用于读取文件、执行函数和处理上下文提示。该协议已被 OpenAI、Google DeepMind 等主要 AI 厂商采用，标志着 AI 行业在互操作性标准方面的重要进展。

从顶级 30 款 AI Agent 产品看三大趋势

36氪发布深度分析，基于市场最顶级的30款 AI Agent 产品总结出三大趋势：底层模型高度集中，大多数 Agent 产品依赖 GPT、Claude 或 Gemini 系列；垂直场景深度定制成为差异化关键；企业级 Agent 基础设施成为大厂必争之地。分析指出，谁在真正高价值的垂直场景里建立起了不可替代的 Agent 基础设施，谁就赢得了从大模型到 Agent 的换道赛。

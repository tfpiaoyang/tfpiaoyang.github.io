🤖 大公司动态

OpenAI 加速 IPO 进程：高盛、摩根士丹利助力，最快九月申报

OpenAI 正推进最快于今年 9 月上市的计划，已聘请高盛和摩根士丹利协助起草上市招股书并尽快向监管机构提交。OpenAI 今年初已融资 1220 亿美元，可能是硅谷最大规模的一轮融资。但近月公司已两度调整产品路线图，先因 Google 竞争，后因 Anthropic 竞争，部分行业观察人士预计 Anthropic 的营收增长可能在数月内超过 OpenAI。

Anthropic Mythos 模型安全争议：担忧被指过度渲染

Anthropic 旗舰模型 Mythos（以及 OpenAI 的 GPT-5.5）引发的国家安全讨论主要围绕 AI 漏洞挖掘能力展开，但业内人士反应更为克制：网络安全专家表示，获取 Mythos 级别的大语言模型并不会立即使此前力所不及的黑客行动成为可能，其计算和基础设施需求也限制了使用者范围。五角大楼将 Anthropic 列为供应链风险，而政府其他部门却在争取获取权限。白宫正与各 AI 实验室讨论更广泛使用其技术的可能性。

[来源：Reuters] 查看详情 | 2026-05-20

Andrej Karpathy 重返前沿大模型研究：选择加入 Anthropic

AI 领域最知名的研究者之一、OpenAI 创始团队成员及特斯拉 Autopilot 架构师 Andrej Karpathy 宣布加入 Anthropic。他表示，希望重返前沿大模型研究。Karpathy 曾于 2022 年创办 Euler 失败的 AI 项目，此前一直在探索新的方向，此次选择 Anthropic 而非他曾工作过的 OpenAI。

[来源：The Decoder] 查看详情 | 2026-05-20

Google I/O 全面更新 AI 订阅：三档定价，最低每月 $10

Google 在 I/O 2026 上公布 AI 订阅体系全面改版：三个档位从 $7.99 到 $99.99 不等，配额逐级递增，同步推出 Gemini 3.5 Flash 新模型。公司还发布了永不疲倦的云端 Agent（Cloud Agent）和重新设计的 Gemini App。Gemini 3.5 Flash 性能大幅提升，但运行成本也相应增加——基准测试中，其运行成本是前代产品的 5.5 倍。

[来源：The Decoder] 查看详情 | 2026-05-20

🚀 技术前沿

Deepseek 正面挑战 Claude Code：正在北京组建代码 Agent 团队

Deepseek 正在北京组建新团队，开发代号”Deepseek Code”的 AI 编程 Agent，直接对标 Anthropic 的 Claude Code 和 OpenAI 的 Codex。新团队正在招募产品经理和开发者，要求熟悉 Claude Code、Cursor、Codex、GitHub Copilot 等工具，了解 Agent 循环、MCP、多 Agent 系统和上下文工程，具备”vibe coding”经验。

[来源：The Decoder] 查看详情 | 2026-05-20

Cohere 发布首个全 Apache 2.0 开源模型 Command A+：无量化损失 + 原生引用

加拿大 AI 实验室 Cohere 推出 Command A+，这是首个完全采用 Apache 2.0 许可的开源大模型，兼具无损量化和原生引用功能。该公司此前刚宣布与德国 AI 创业公司 Aleph Alpha 合并，Command A+ 的发布是面向企业构建者的又一重磅产品，论文合著者包括《Attention Is All You Need》联合作者 Aidan Gomez。

[来源：VentureBeat] 查看详情 | 2026-05-20

Cerebras 芯片运行万亿参数模型：速度比 GPU 云快近 7 倍

Cerebras 在完成 2026 年最大科技 IPO 不到一周后，宣布其芯片现在运行 Kimi K2.6——一个万亿参数开源权重模型——比 GPU 云快近 7 倍。这家芯片制造商正试图主导快速增长的 AI 推理市场。Kimi K2.6 由月之暗面（Moonshot AI）开发，Cerebras 为其提供推理加速。

[来源：VentureBeat] 查看详情 | 2026-05-20

Google 推出托管 Agent API：一键部署，但牺牲执行层控制

Google 在 I/O 上推出 Gemini API 托管 Agent（Managed Agents）服务，承诺将数周的 Agent 部署工作压缩为一次 API 调用。这也释放了一个信号：Google 认为其生态系统（包括新发布的 Antigravity CLI）已准备好掌控执行层。

[来源：VentureBeat] 查看详情 | 2026-05-20

🛡️ 安全与风险

GitHub 确认 3800 个内部仓库遭供应链攻击窃取

GitHub 5 月 20 日确认，一个通过投毒 VS Code 扩展侵入员工设备的攻击者获得了微软旗下代码存储和协作平台约 3800 个内部仓库的访问权限。攻击组织 TeamPCP（由 Google 威胁情报团队追踪为 UNC4899）使用被污染的 VS Code 扩展和微软 Python SDK 进行供应链攻击。

[来源：VentureBeat] 查看详情 | 2026-05-20

企业 AI Agent 频陷失败：根因在于”学会就忘”

RAG 架构擅长一件事：检索语义相关文档——但也仅此而已。一款名为 Decision Context Graph 的框架正试图解决这一痛点，通过为 Agent 提供结构化记忆、时间感知推理和显式决策逻辑。Neo4j 旗下 Rippletide 初创公司的研究指出，现有 Agent 在长期任务中会逐渐丢失已学到的上下文知识。

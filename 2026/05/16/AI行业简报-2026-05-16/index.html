🚀 AI行业动态

Greg Brockman 正式接管 OpenAI 所有产品线

OpenAI 再次进行高管层重组，Greg Brockman 正式接管 ChatGPT 和 Codex 所有产品线，这是公司统一产品体验努力的一部分。前 CTO Mira Murati 创立的 Thinking Machines Lab 也在本周发声，表示其AI产品将”让人类保持参与其中”，而非替代人类。

[来源：Wired] 查看详情 | 2026-05-15

OpenAI 发布更便宜的模型定价 tiers，最高降价30%

OpenAI 宣布为旗下模型推出更低价位层，降幅最高达30%，旨在提升开发者和企业的可及性。新的定价层立即生效。同时有报道称 OpenAI 正重新考虑”无限量”订阅计划，随着AI成本和用量的激增，现有的无限量模式可能走向终结。

[来源：TechCrunch] 查看详情 | 2026-05-15

Microsoft 发布3款新AI模型，直接挑战 OpenAI 和 Google

Microsoft 发布了3款新AI模型，直接对准 OpenAI 和 Google 的市场份额。这一动作的背景是：直到2025年10月，Microsoft 在合同上被禁止独立追求通用人工智能（AGI），但随着 OpenAI 扩展与 SoftBank 等其他公司的合作，Microsoft 重新谈判了协议条款，现已获得独立追求AGI的权利。Microsoft 小团队（据说仅10名工程师）即可打造一流模型，这正在改变AI的经济学结构。

[来源：VentureBeat] 查看详情 | 2026-05-15

AI驱动的裁员潮：2026年科技行业已裁减超10万个岗位

2026年前五个月，全球科技公司已因AI和自动化裁员超过10万人。Freshworks 裁员约11%（约500人），Coinbase 裁员14%，Meta、Oracle 等大型企业也加入裁员行列。企业正转向更精简的AI原生运营模式。

[来源：VarIndia / Reuters] 查看详情 | 2026-05-15

Anthropic 在企业AI采用率上超越 OpenAI

Anthropic 在企业AI采用率上实现里程碑式超越，Claude 达到34.4%的采用率，超越 OpenAI 的2.9%下滑。Anthropic 定位为”安全优先”和”编程优化”的替代方案，在金融、法律和软件开发领域获得认可。Claude Code 年化营收已达25亿美元。

[来源：KuCoin Blog / TechCrunch] 查看详情 | 2026-05-15

Meta 宣布即将发布 LLaMA 商业版开源模型

Meta（Facebook）准备发布 LLaMA 的商业版本，这将使开发者和企业能够基于 LLaMA 构建应用。LLaMA 在2月作为小型基础模型向研究人员和学术界发布，现在商业版本将使其与 Microsoft 支持的 OpenAI 和 Google 直接竞争，对开源生态意义重大。

[来源：ZDNET] 查看详情 | 2026-05-15

白宫介入AI安全评估，前沿模型发布前需政府审查

Microsoft、Google、xAI 承诺在发布最新前沿AI系统前，与美国商务部的AI标准和创新中心（CAISI）分享并进行安全评估。Anthropic 的 Claude Mythos 和 OpenAI 的 GPT-5.5 均已进入美国政府安全评测流程。此举源于对前沿模型网络能力的担忧，Claude Mythos 被描述为能够执行端到端网络攻击模拟，已超越现有安全基准。

[来源：Transformer Weekly / lablab.ai] 查看详情 | 2026-05-15

Google 准备在 I/O 大会发布新 Gemini 模型，目标对标 GPT-5.5

Google 计划于5月19日的I/O开发者大会上发布新的 Gemini 模型，目标是与 OpenAI 的 GPT-5.5 竞争，并计划进一步超越。新模型将驱动新的 Android AI 功能，包括跨多应用的自动化功能。

[来源：Android Headlines] 查看详情 | 2026-05-15

OpenAI 融资100亿美元谈判进行中，Musk 诉讼案接近尾声

OpenAI 正在洽谈一轮可能达到1000亿美元的融资。同时 Elon Musk 起诉 OpenAI 及 Microsoft 的审判接近尾声，Musk 律师在结案陈词中指责 Sam Altman 的信誉问题，要求获得约1500亿美元的赔偿。

[来源：Economic Times / AFR] 查看详情 | 2026-05-15
